# Limites da auditoria

A auditoria compara os arquivos existentes do repositório com os requisitos de produto consolidados em `MASTER_SPEC.md` e `SCOPE_MATRIX.json`.

O material histórico completo e anexos antigos não estavam disponíveis para conferência. Por isso, não é possível atestar se conteúdos que não estão no repositório foram preservados. As regras já recuperadas estão organizadas na especificação mestre; valores indicados como candidatos ou sugestões continuam pendentes de decisão.

A auditoria não acessou banco de produção, contas de pagamento, consoles de publicação, credenciais ou dados de clientes.
